# Fire Extinguisher Mod - Project Overview

## General Information
- **Mod Name:** Fire Extinguisher Prototype
- **Mod ID:** `fireextinguisherprototype`
- **Version:** 1.0.0
- **Platform:** Fabric (Current) -> NeoForge (Target)
- **Minecraft Version:** 1.21

## Summary
The Fire Extinguisher mod adds a functional tool that allows players to extinguish fires, soul fires, and lit blocks (like candles and campfires) using a pressurized spray. It features a custom spray logic that calculates a cone of effect in front of the player, complete with visual particles and sound effects.

## Key Design Principles
1. **Utility:** A specialized tool for fire safety and management.
2. **Visual Feedback:** Dense foam-like spray using vanilla particles (`CLOUD`, `POOF`, `SMOKE`).
3. **Sound Immersion:** Uses the standard fire extinguish sound in a loop while spraying.
4. **Intuitive Use:** Hold right-click to spray continuously.
