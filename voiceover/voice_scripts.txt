================================================================
BERONGSMP — FULL CHARACTER SCRIPTS FOR TTS GENERATION
================================================================
Instructions:
  1. Go to elevenlabs.io
  2. Pick a voice for each character (use the same voice for ALL
     lines of that character)
  3. Paste the ENTIRE script block for one character at once
  4. Generate → download as one MP3
  5. Open in Audacity — cut at each [pause] gap
  6. Export each chunk as OGG with the filename shown above each line
  7. Place all OGG files in:
     src/main/resources/assets/berongsmp/sounds/npc/

Suggested ElevenLabs voices:
  Sgt. Reyes   — deep, authoritative male (e.g. "Daniel" or "Antoni")
  Officer Cruz — warm, friendly female (e.g. "Rachel" or "Bella")
  Capt. Santos — strong, commanding female (e.g. "Elli" or "Charlotte")
================================================================

================================================================
AUDACITY CUTTING GUIDE
================================================================
1. Open the MP3 in Audacity
2. Zoom in on the waveform — silence gaps between lines are easy to see
3. Click at the START of a silence gap → Edit → Clip Boundaries → Split
4. Click at the END of the same silence gap → Split again
5. Click the silent chunk → Delete
6. Select the line you want → File → Export → Export Selected Audio
7. Choose OGG Vorbis format, name it exactly as shown (e.g. sgt_reyes_0)
8. Repeat for every line

TIP: Use Audacity's label track to mark all cut points first,
     then export in bulk using File → Export → Export Multiple.

ffmpeg one-liner to convert a whole folder of MP3s to OGG:
  for f in *.mp3; do ffmpeg -i "$f" -c:a libvorbis "${f%.mp3}.ogg"; done
