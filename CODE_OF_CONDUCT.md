# Code of Conduct

## Our expectations

BerongSMP is a university thesis project with a public GitHub presence. Anyone interacting here,
whether opening an issue, commenting on one, or reaching out about the project, is expected to be
respectful and constructive. In short:

- Be considerate. Assume good faith, and give feedback the way you would want to receive it.
- Stay on topic. Issues and discussions should be about the project: bugs, questions, ideas,
  documentation, or the thesis work it supports.
- No harassment, discrimination, or personal attacks, toward the maintainer or anyone else who
  comments here.
- No spam, self-promotion unrelated to the project, or off-topic advertising.

## Scope

This applies to any space connected to this repository: issues, pull requests, discussions, and
commit or code review comments.

## Reporting a problem

If someone's conduct in this repository does not meet the expectations above, please reach out
through the repository's GitHub page (for example, by messaging the repository owner directly)
rather than escalating in a public thread. Reports will be handled privately and taken seriously.

## Enforcement

Comments, issues, or pull requests that violate this code of conduct may be edited, locked, or
removed, and repeat or severe violations may result in being blocked from the repository. This is a
small, single maintainer project, so enforcement is applied with judgment rather than a fixed
escalation ladder, but the goal is always to keep this a welcoming, low drama place to discuss the
work.
