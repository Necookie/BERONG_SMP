BerongSMP - Client Setup
=========================

WHAT THIS IS
------------
This installs everything you need to join the BerongSMP server:
the NeoForge mod loader (version 26.2.0.7-beta) and the BerongSMP mod itself.

BEFORE YOU START
-----------------
You need Minecraft Java Edition (not Bedrock/Windows 10 Edition) and you
must have opened the official Minecraft Launcher and pressed Play at
least once before. If you've never done that, open the Minecraft
Launcher now, let it load, then come back to this installer.

HOW TO INSTALL
---------------
1. Keep "Install-BerongSMP.exe" and the "payload" folder together in the
   same folder - do not move the .exe out on its own.

2. Double-click "Install-BerongSMP.exe".

3. Windows will probably show a blue "Windows protected your PC" screen.
   This is normal for a small installer like this one - it just means
   the file isn't from a big well-known publisher, not that it's unsafe.
   Click "More info", then click "Run anyway".

4. A black window will open and do the setup automatically:
     - checks that Minecraft is installed
     - finds Java
     - installs NeoForge 26.2.0.7-beta
     - installs the BerongSMP mod
   This takes a minute or two. When it says "Install complete!", press
   Enter to close the window.

AFTER INSTALLING
------------------
1. Open the Minecraft Launcher.
2. In the profile dropdown (top of the Play button), select
   "NeoForge 26.2.0.7-beta".
3. Click Play.
4. Once you're in the game, go to Multiplayer.
5. Click "Add Server".
6. Server Address: berongsmp.mcsh.io
7. Click Done, then double-click the server to join.

TROUBLESHOOTING
-----------------
- "Could not find a Minecraft installation" -> open the Minecraft
  Launcher and press Play once first, then run the installer again.
- "Could not find a Java runtime" -> same fix as above.
- The window closes instantly / you can't read it -> right-click
  Install-BerongSMP.exe and choose "Run as administrator", or let us
  know so we can help.
- Can't connect to the server -> double check the server address was
  typed/pasted exactly, and that you selected the NeoForge 26.2.0.7-beta
  profile (not vanilla/plain Minecraft) before clicking Play.
