# Migration History: From Fabric to NeoForge

## Context
The project began as the **Fire Extinguisher Prototype**, a Fabric-based mod for Minecraft 1.21. Its goal was to create a realistic fire extinguisher tool.

## Transition to BerongSMP
The decision was made to expand the scope into a full disaster simulation platform, and the project was migrated to **NeoForge**.

## Migration Details (See `migrations/` folder)
The `migrations` folder contains detailed notes used during this transition:
- **`OVERVIEW.md`**: Summary of the original prototype.
- **`FUNCTIONALITIES.md`**: Breakdown of the original mod's features.
- **`TECHNICAL_DETAILS.md`**: Technical specifics of the original implementation.
- **`MIGRATION_GUIDE.md`**: Instructions for porting the logic from Fabric to NeoForge.
- **`CONVERSION_INSTRUCTIONS.md`**: Detailed mapping of classes and methods.
- **`ASSETS_AND_RESOURCES.md`**: Guide for porting textures and models.

## Current Status
The project is now fully established on NeoForge as **BerongSMP**, with the Fire Extinguisher successfully integrated as a core tool within the broader simulation framework.
