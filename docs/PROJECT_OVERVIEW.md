# Project Overview: BerongSMP

## Summary
**BerongSMP** is a Minecraft mod built on the **NeoForge** platform (Minecraft 1.21). It is designed as a disaster simulation environment, specifically focusing on fire and earthquake safety training.

The project originated from a Fabric-based prototype called "Fire Extinguisher Prototype" and has evolved into a more comprehensive simulation platform.

## Core Features
- **Simulation Manager**: Orchestrates disaster scenarios (Fire, Earthquake) within a controlled environment.
- **Lobby System**: Provides a safe area for players to wait and prepare before starting simulations.
- **Fire Extinguisher**: A functional tool for extinguishing fires, ported and enhanced from the original prototype.
- **Custom Structures**: Uses Minecraft's structure system (NBT) to load complex simulation environments (e.g., the LSPU Library).
- **HUD and UI**: Real-time feedback for players during simulations, including timers and status updates.

## Technical Goals
- **Realism**: Providing a convincing simulation of disaster scenarios.
- **Educational Value**: Helping players understand fire safety and earthquake response protocols.
- **Modularity**: Easy addition of new simulation types and structures.
